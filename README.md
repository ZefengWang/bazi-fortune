# 八字命理排盘引擎（学习演示版）

> ⚠️ **免责声明**：本项目为基于传统四柱八字理论编写的**技术演示程序**，内容不构成任何形式的人生、健康、投资、婚恋等建议，亦不代表任何科学结论。**仅供个人学习与编程研究使用，严格禁止任何商业用途**（包括但不限于付费算命、引流变现、植入广告、打包转售等）。请理性看待传统文化。

## 简介

一个纯静态的前端八字排盘演示页面，由 Python 命理引擎逐行移植为 JavaScript 实现，核心逻辑保持一致：

- 天干地支、五行、阴阳符号集
- 十神关系判定（比肩/劫财/正印/偏印/食神/伤官/正官/七杀/正财/偏财）
- 儒略日（Julian Day）换算与历史历法校验（含公元 0 年边界、1582 历法切换、闰年）
- 真太阳时物理纠偏（经度 + 均时差方程）
- 四柱（年月日时）干支排盘
- 五行能量统计与身强/身弱判断
- 十种格局详解（性格、事业、解局思路）

## 使用方式

直接用浏览器打开 `index.html`，输入出生年月日时、出生地（省份或自定义经度）与时间类型，即可生成排盘结果。全程本地计算，无后端依赖。

## 文件结构

- `index.html`：页面结构与交互逻辑
- `engine.js`：核心命理引擎（浏览器与 Node 双端可运行）
- `assets/logo.jpg`：项目 Logo
